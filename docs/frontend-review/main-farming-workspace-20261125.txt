영농관리 메인 화면 연결 — 2026-11-25

수정 대상
- /#/farming-workspace의 1. 영농계획 → 2. 사진 갤러리 → 3. 수행 기록
  → 4. 보고서 → 5. 현장 확인을 메인 업무 흐름으로 유지
- 별도 운영 화면으로 이동하지 않고 위 탭 안에서 운영 API 사용
- 실제 계정은 운영 자료가 기본. 기존 샘플 시연은 별도 버튼으로 제공
- 기존 샘플 브라우저 저장 자료는 변경·삭제·자동 이관하지 않음

1. 영농계획
- GET /crop-guides, GET /crop-guides/{guide_id}로 서버 가이드 조회
- 재배 연도·월별 가이드·일정 조정·인력·장비·설명 작성
- POST /farming-plan-submissions로 연간계획과 작업 계획들을 한 번에 등록
  guide_version_id, plan_year, equipment, available_manpower, task_adjustments 사용
- 같은 발전소·연도·작물의 중복 제출 차단, 조정 사유를 설명에 보관
- GET /farming-plan-submissions, GET /farming-plans로 등록 계획 선택
- 수정 권한이 있으면 PATCH /farming-plans/{id}로 작업명·기간·설명 수정
  연결된 확정 활동과 기간이 어긋나는 수정은 사전에 차단
- 서버에 등록된 가이드의 실제 작업 수와 일정을 표시. 샘플의 12개 작업으로 강제하지 않음
- 관리자 카메라 설정·촬영 정책은 이 탭 안의 '카메라 · 자동 촬영 설정'에서 처리
  기존 장비·Runtime·Policy API 사용, 실제 영상 정상 상태를 추정하지 않음

2. 사진 갤러리
- 실제 Vision Analysis 목록·상세·원본·분석 이미지·검토 이력 조회
- 촬영 기간·상태·탐지 대상 검색, 페이지 이동
- 업로드 권한이 있는 담당자는 이미지 최대 20장·각 8MB를 선택해 한 장씩 분석
  기존 POST /vision/detect 사용. 중간 실패 시 중지하고 목록 확인 안내
- 검수자 확정 전 사진과 다른 활동이 점유한 사진은 활동 첨부 불가
- 검수자는 이 탭에서 PATCH /vision/analyses/{id}/review로 사진 확정·반려
- 확정 사진을 여러 장 선택하고 '수행 내용 작성'으로 3번 탭에 전달
- 실제 생육 단계 정보가 없는 사진을 임의로 4단계 분류하지 않음

3. 수행 기록
- 선택한 작업 계획의 유형과 사진 촬영일을 비교한 후 활동 제출
- POST /farming-activities의 analysis_ids[]로 여러 사진을 한 활동에 저장
- 반려 사유를 확인하고 PATCH /farming-activities/{id}로 같은 활동 재제출
- 검수자는 활동 확정 후 POST /farming-plans/{id}/matches로 실제 계획 연결
- 확정과 매칭은 별도 요청. 연결만 실패한 경우 확정을 반복하지 않고 연결만 재시도
- 계획 종료 다음 날부터 기존 이행 평가 API로 최종 평가 저장
- 다른 계정 처리 결과는 탭 진입·창 포커스·새로고침으로 조회
- 새 조회 중에도 작성 중인 양식은 유지. 서버 쓰기는 최신 상태를 검증

4. 보고서
- 기존 /farming-plans/reports/data, generate, archive, download 사용
- 같은 화면에서 기간 조회·PDF 생성·보관 파일별 검토·승인·반려·다운로드
- 승인 API는 서버가 로그인 사용자의 이름·역할·시각을 기록
- 샘플 시연 역할 전환으로 실제 승인할 수 없으며, 실제 계정 permissions 적용
- 원본 PDF의 빈 서명란을 웹 승인 기록으로 채우는 백엔드 변경은 포함하지 않음

5. 현장 확인
- 현장 요청·조치 공유용 API는 현재 없음
- '개인 메모'로 명확히 표시하고 계정·발전소별 이 브라우저에 보관
- 사진 상세에서 관련 사진을 연결해 개인 메모 작성 가능
- 다른 계정에 요청을 보냈거나 서버에 저장됐다고 표시하지 않음

검증

- 기존 test:camera 5개 그룹과 test:browser 8개 그룹 통과
- 자동화 쓰기는 메모리 fixture 사용. 운영 데이터 생성·변경 없음
- 실제 화성 담당자·검수자·admin으로 1~5번 탭 조회:
  페이지 오류 0건, API 오류 0건, 업무 쓰기 요청 0건
- 실제 CCTV 장비·RTSP 자동 촬영은 장비 준비 후 별도 검증 필요
